    Comment publier vos changements
    Ce site est statique : cette page ne peut rien écrire sur le serveur. Elle travaille en mémoire (et garde un brouillon dans votre navigateur). Quand vous avez terminé, cliquez sur Exporter products.json, remplacez tools/data/products.json par le fichier téléchargé, puis lancez python3 tools/build_pages.py et publiez.

    Les liens vidéo sont enregistrés et affichés comme un simple lien sortant : le site ne contient aucune vidéo intégrée.

    À lire : où sont réellement vos demandes
    Ce site est statique, sans serveur ni base de données. Le formulaire enregistre chaque demande dans le localStorage du navigateur du visiteur, puis l'envoie vers WhatsApp avec le récapitulatif pré-rempli.

    Autrement dit : une demande envoyée depuis le téléphone d'un client est stockée sur ce téléphone, pas ici. Ce tableau ne montre que les demandes saisies dans ce navigateur (vos tests, ou un client qui remplirait le formulaire sur votre poste). Les conversations reçues sur le WhatsApp du 05 37 75 97 72 restent votre véritable registre de leads.

    Pour un vrai registre centralisé, il faut un service de formulaire (Formspree, Netlify Forms, Google Forms…) ou un back-end : dites-le-nous et nous le branchons.
